# Ciudad Transparente

Juego educativo en HTML5 Canvas sobre prevención del lavado de dinero y detección de incoherencia patrimonial.

## Cómo ejecutar

1. Descarga o clona este repositorio.
2. Abre `index.html` directamente en tu navegador.
3. También puedes servir la carpeta con un servidor local si prefieres, por ejemplo:

```bash
python -m http.server 8000
```

Luego abre:

```text
http://localhost:8000
```

## Contenido del juego

- Ciudad pequeña con seis ubicaciones clave.
- Movimiento con teclado: flechas o WASD.
- Diferenciación entre ingresos legítimos y efectivo no verificado.
- Riesgo financiero visible y nivel de alerta.
- Compras de alto valor que activan alerta y persecución.
- Tres niveles educativos.
- Pantalla final con puntuación, señales y conclusiones.
